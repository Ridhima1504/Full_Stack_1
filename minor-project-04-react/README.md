# FocusNest — React Minor Project 04

FocusNest is a unique React-based productivity dashboard containing two applications:

1. To-Do App
2. Notes App

## Features

### To-Do App
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Edit tasks
- Pending/completed status
- All/Pending/Completed filters
- Due dates
- LocalStorage persistence

### Notes App
- Create notes
- Edit notes
- Delete notes
- Search notes
- Categories
- Timestamps
- Organized responsive card layout
- LocalStorage persistence
